# Security reporting

## Supported release

Security fixes target the latest source-alpha release. Older alpha snapshots
are not maintained separately. This is an experimental client and host
integration, not a production-support commitment.

## Report privately

Use [Report a vulnerability](https://github.com/chektien/vimicate/security/advisories/new)
in this repository's **Security** tab to open a private GitHub advisory for the
maintainers. Do not post security-sensitive
details in public issues, pull requests or discussions.

Include the affected release or commit, OpenClaw version, platform, expected
behavior, observed behavior and a minimal synthetic reproduction. Describe the
impact and any workaround you have verified.

Never include real pairing codes, provider tokens, private conversations,
device databases, signing credentials or signed download URLs. Replace them
with synthetic data. If you have accidentally exposed a credential, revoke it
through its issuing service before sharing the reproduction.

The maintainer will investigate and coordinate disclosure through the private
advisory. No response-time guarantee or bounty is offered. Please keep the
report private while a fix and disclosure plan are being coordinated.
